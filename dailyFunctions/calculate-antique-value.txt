class CalculateAntiqueValue {
    public static int calculateAntiqueValue(int originalPrice, int restorationFeePercent) {
        return (int) Math.round(originalPrice* (1+restorationFeePercent/100.0));
    }
}

The function calculates the total value of an antique item by adding the restoration fee to the original franc price and rounding to the nearest integer.

    originalPrice (int): The original price of the antique item in francs
    restorationFeePercent (int): The restoration fee as a percentage (e.g., 15 means 15%)
